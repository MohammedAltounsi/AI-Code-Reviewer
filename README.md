# AI Code Reviewer

Paste code, or a GitHub file URL. Get a structured code review back: a
Code Health Score, findings grouped by category (security, bugs,
performance, style, best-practices), severity ranked, each with a specific
fix. Export as Markdown (for a PR comment) or CSV.

**Live:** https://ai-code-reviewer-coral-five.vercel.app

## The core design decision

The Health Score is never generated by the model. It's a fixed
point-deduction formula over Claude's categorized findings — critical
−25, high −15, medium −7, low −2, floored at 0 — computed in code every
time. Claude decides what's wrong and how severe; arithmetic decides the
number. Same principle as the companion project, [AI Website
Auditor](https://github.com/MohammedAltounsi/AI-Website-Auditor), applied
where there's no external scoring API to average.

## How it works

1. **`lib/githubFetch.ts`** — if given a GitHub file URL, parses it with a
   strict regex into `owner`/`repo`/`branch`/`path`, then fetches from
   `raw.githubusercontent.com` — a host this code builds itself, never one
   taken from user input. That sidesteps the SSRF problem class entirely:
   there's no arbitrary-host fetch to protect against, because the
   destination host is fixed by the code, not the request.
2. **`lib/analyze.ts`** — sends the code to Claude via forced tool-use
   (`tool_choice: { type: 'tool' }`), so the response is always a validated
   structured object, never free text to parse.
3. **`lib/score.ts`** — computes the Health Score from the findings list.
4. **`app/api/review/route.ts`** — runs the pipeline, enforces a 50KB
   pasted-code cap and a 200KB GitHub-fetch cap, returns one JSON report.
5. **`app/page.tsx` + `app/components/*`** — paste-code / GitHub-URL toggle,
   animated Health Score gauge, category counts, severity-badged findings,
   Markdown and CSV export.

## Scope

Reviews one file at a time — pasted snippet or a single GitHub blob URL.
No full-repo cloning, no code execution or sandboxing: the submitted code
is only ever sent to Claude as text for static analysis, never run.

## Stack

Next.js (App Router) + TypeScript + Tailwind, Anthropic API
(`claude-sonnet-5`, forced tool-use), Vitest + Testing Library.

## Setup

```bash
npm install
cp .env.local.example .env.local
# fill in ANTHROPIC_API_KEY (console.anthropic.com)
npm run dev
```

## Testing

```bash
npm test
```

## Known limitation

The GitHub blob-URL regex assumes the branch name contains no `/` — covers
`main`, `master`, `develop`, most feature branches. A branch like
`feature/x` returns a clear 400 error instead of mis-parsing.

## Future improvements

- Full-repo review mode (walk the tree, pick files, handle rate limits) — a meaningfully bigger product than this.
- Syntax highlighting in the paste textarea (CodeMirror/Monaco).
- Rate limit by IP (Vercel KV) once the tool gets real traffic.
- Diff-aware review — paste a diff instead of a whole file.
